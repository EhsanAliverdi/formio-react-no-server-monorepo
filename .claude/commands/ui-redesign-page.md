Use the ui-ux-designer skill.

Redesign and improve the selected Angular page.

Target page or component:

$ARGUMENTS

Application URL:

http://localhost:4200

Tasks:

1. Inspect the target component, template, SCSS/CSS, and related shared components.
2. Use Playwright MCP to open the page.
3. Capture a before screenshot.
4. Identify the main UI/UX problems.
5. Implement a clean, professional redesign.
6. Preserve all business logic and existing data bindings.
7. Improve spacing, hierarchy, cards, forms, tables, buttons, empty states, and responsive behaviour.
8. Add or improve accessibility where appropriate.
9. Run the relevant build/lint/test commands.
10. Capture an after screenshot if possible.

At the end, report:

- Problems found
- Files changed
- Improvements made
- Commands run
- Before/after screenshot paths
- Remaining recommendations
