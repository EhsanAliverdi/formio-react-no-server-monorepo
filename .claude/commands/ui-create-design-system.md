Use the ui-ux-designer skill.

Create a lightweight design system for this Angular application.

Tasks:

1. Inspect current global styles, theme files, components, buttons, cards, forms, tables, layout, and spacing.
2. Identify inconsistencies.
3. Create or update a lightweight design system without introducing a new UI library unless necessary.
4. Define reusable tokens for:
   - Colours
   - Typography
   - Spacing
   - Border radius
   - Shadows
   - Form styles
   - Button styles
   - Card styles
   - Table styles
   - Status colours
5. Create or update:

docs/ui-ux/design-system.md

6. If suitable, add or update shared SCSS/CSS files.
7. Do not rewrite the whole app.
8. Keep changes incremental and safe.

At the end, report:

- Design tokens created
- Shared styles/components changed
- Files changed
- Migration recommendations for existing pages
